RICA FERREIRA — SITE DE PRODUÇÃO AUDIOVISUAL

ARQUIVOS
- index.html: estrutura e conteúdo do site.
- styles.css: identidade visual, layout e responsividade.
- script.js: menu mobile, ano automático e formulário para WhatsApp.

COMO TESTAR
1. Extraia a pasta do ZIP.
2. Abra o arquivo index.html no navegador.
3. Para editar, abra a pasta no VS Code.

ANTES DE PUBLICAR — PERSONALIZAÇÕES IMPORTANTES
1. Abra script.js e altere WHATSAPP_NUMBER.
   Use somente números: código do país + DDD + telefone.
   Exemplo de formato: 5511999999999.
2. Substitua as imagens ilustrativas do portfólio por trabalhos reais.
   As imagens estão no index.html, em tags <img>.
3. Troque as imagens de capa no styles.css (busque por "unsplash.com").
4. Confirme os serviços, textos, região de atendimento e links de redes sociais.
5. O formulário abre uma conversa no WhatsApp; ele não armazena dados em servidor.

PUBLICAÇÃO
O site é estático e pode ser publicado no Netlify, GitHub Pages ou hospedagem tradicional.
Basta enviar index.html, styles.css e script.js mantendo os três na mesma pasta.

Observação: as fontes e imagens externas precisam de conexão com a internet para carregar.
